# TraderMoving

搬运商人的无线电和交易箱。The Long Dark 2.55 + MelonLoader,要有 Tales from the Far Territory DLC。

前置 mod 是 ModSettings 和 ModData。不需要 SafehouseCustomizationPlus,装了也不冲突。

## 怎么用

1. 看着无线电或交易箱,按一下 `Y`(可改),屏幕提示已选中。
2. 点右键抱起来。抱着时不能冲刺、不能拿别的东西,体力和热量按重量多耗。
3. 走到想放的地方按 `Y` 或右键,出现蓝色虚影。滚轮转方向,左键放下,右键取消(取消了还抱着)。

选中后 8 秒不动或者视线移开会自动取消。装修模式里对无线电或交易箱点"拿起"也行,会自动退出装修模式再抱起来。受伤、搏斗、攀绳时会直接放在脚前。

## 交易箱

放在哪都行,读档以后还在原地。放好以后,不管在哪台无线电下单,商人都把货送到这个箱子。

箱子里已经放了货、交易已经关上等商人确认、或者奖励还没拿走的时候,不让搬这个箱子。还没放货的交易可以搬,放下后这笔交易跟着改送到新位置。

## 无线电

放回它原来那间屋子里,就是原版那台。放在别的场景,是从原版那台完整复制出来的一台,对话、交易、取消交易都和原版一样,按住交互键呼叫商人。

复制需要原版那台在眼前。抱起时会顺手复制一份;读档后如果你在别的场景,mod 会在后台把无线电原来的场景单独加载一下,复制完马上卸掉,前后一两秒,期间无线电还没出现是正常的。

复制失败时(日志里会写原因)退回随身无线电。随身无线电用美术模型做的,看着它按 `Y` 选中,再按一次 `Y` 呼叫商人。

1. 没有交易时打开选货面板下单,货送到你搬的交易箱。要先搬好一个交易箱。
2. 交易进行中会提示交易箱在哪。
3. 货放齐、箱子关上以后再呼叫一次,就完成交易,去箱子里拿奖励。

随身无线电没有语音对话,也不能取消交易,这两样要回原版无线电上做。第一次联系商人也要在原版无线电上。

和原版一样,要商人已经到了、极光来了、上一单送完的冷却过了才联系得上。设置里开了随身无线电不用等极光,或者 TldHacks 开了商人常驻,就随时能呼叫。

## 设置

在 Mod Settings 里的 TraderMoving 页。

| 项 | 默认 | 说明 |
|---|---|---|
| 启用搬运无线电 | 开 | |
| 启用搬运交易箱 | 开 | |
| 选中键 | Y | |
| 诊断键 | F9 | 把现在的状态写进日志 |
| 无线电重量 | 6 公斤 | 抱着时多算的负重 |
| 交易箱重量 | 10 公斤 | |
| 受伤时也能搬 | 关 | |
| 货送到我搬的交易箱 | 开 | |
| 随身无线电不用等极光 | 关 | |
| 箱里有货时禁止搬交易箱 | 开 | 建议一直开着 |
| 放回原处 | | 打开后点确认,两样都回到原版位置 |

## 限制

1. 一个存档只能搬一台无线电和一个交易箱。想换一台,先把搬过的放回原处。
2. 存档以后位置才记下来。没存档就退出,下次还在上次存档时的样子。

## 出问题时

按 `F9`,把 `MelonLoader\Latest.log` 里 `TraderMoving 诊断` 那一段发给作者。启动时日志里的 `[TraderMoving.SelfCheck]` 那行如果报找不到,说明游戏更新改了接口。

## 构建

```
dotnet build TraderMoving/src/TraderMoving.csproj                    # 编译并部署到 Mods
dotnet build TraderMoving/src/TraderMoving.csproj -p:NoDeploy=true   # 只编译
```

交易箱的做法参考了 Fuar 的 ImprovedTrader。
