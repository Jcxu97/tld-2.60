## 三、安装步骤
### 装之前
+ 嫌麻烦或者怕装错的，直接找群主远程安装，30 元一次，见第一章。
+ 先装网盘根目录的 .NET 运行库（前置！必须下载安装！那个 exe），装过就跳过。
+ 游戏要是 2.60 版。
+ 解压用 7-Zip（WinRAR 新版、Bandizip 也行）。Windows 自带的解压不认分卷和带密码的 7z。
+ 以前装过别的 mod 或别人整合包的，建议先把游戏根目录的 Mods、MelonLoader、UserData、UserLibs、Plugins 这几个文件夹和 version.dll、winhttp.dll 挪走或删掉，再装，免得新旧混在一起。
### 游戏根目录在哪
游戏根目录就是有 tld.exe 的那个文件夹。在 Steam 库里右键 The Long Dark，管理，浏览本地文件，打开的就是。
Steam 默认在 D:\Steam\steamapps\common\TheLongDark\（或 C 盘，看你 Steam 装在哪）。
### 最小包
+ 解压 TldHacks-v12.3-最小安装包_只带修改mod！解压到游戏根目录.zip，里面是 version.dll、MelonLoader、Mods 三样。
+ 把这三样拖进游戏根目录，和 tld.exe 同一层，提示重名就选覆盖。
+ 以前单独装过被整合的 mod，或者装过别人整合包的，按第四章跑一次 bat。
+ 启动游戏，进存档后按 Tab 打开 TldHacks 菜单。
### 完整版
+ 下载完整版文件夹里的四个分卷 材质包备份.001、.002、.003、.004，放在同一个文件夹里。四个缺一个都会报“无法打开为压缩文件”。
+ 右键 材质包备份.001，用 7-Zip 打开，输入密码 tld2026。只点 .001 就行，它会自动把四个分卷合起来。
+ 解压出来是一个长名字的文件夹。打开它，把里面的 version.dll、MelonLoader、Mods 三样拖进游戏根目录，选覆盖。拖的是里面的东西，不要把那个长名字文件夹本身拖进去。
+ 进游戏根目录的 Mods 文件夹，双击 disable_integrated_mods.bat（见第四章）。
+ 启动游戏，进存档后按 Tab 打开 TldHacks 菜单。
要改按键和其他设置，进游戏后在 Mod Settings 里改。包里带的是我自己的 mod 设置，大家按自己的习惯重新设一遍。
### 终极版 - 找群主远程才能解锁
+ 下载终极版文件夹里的全部 182 个分卷 终极版材质包备份.001 到 .182，放在同一个文件夹里，缺一个都解不开。
+ 右键 终极版材质包备份.001，用 7-Zip 打开，输入密码 tld2026。只点 .001 就行，它会自动把后面的分卷接上。
+ 把解压出来的 winhttp.dll、MelonLoader、Mods、UserData、UserLibs、Plugins 全部放进游戏根目录，直接和 tld.exe 同一层，不要多套一层文件夹。有重名就覆盖。
+ 启动游戏。第一次启动会多等一会儿，黑框里刷字是正常的。
+ 进存档后按 Tab 打开 TldHacks 菜单。修改器是默认设置，作弊开关全是关的，要用什么自己在菜单里开。别的 mod 的按键和完整版有些不一样，见第七章。
旧完整版用的是 version.dll，终极版用的是 winhttp.dll，两个只留一个。
### 剧情包
剧情包装在别的文件夹，不是游戏根目录，见第九章。

## 四、装完先做这一步
装完完整版，第一件事是进游戏根目录的 Mods 文件夹，双击 disable_integrated_mods.bat。游戏开着的时候它会提示先关游戏。
它会把已经整合进 TldHacks 的旧 mod 挪进 Mods\_disabled 文件夹。不停用的话，同一个功能被两个 mod 同时改，会冲突或者叠在一起。停用哪些 mod 见第八章。
最小包里没有这个 bat，用网盘根目录那份（如果装了别人的整合包需要放到mods文件夹双击运行.bat），放进 Mods 文件夹再双击。
装过别人整合包的，或者以前单独装过第八章那些 mod 的，一定要跑一次。

## 五、TldHacks 功能介绍
TldHacks 是内置修改器，三个沙盒包都带，用在沙盒模式。剧情模式用第九章的剧情包，里面是剧情专用的一份。
### 打开菜单
+ 进存档后按 Tab 打开菜单，再按一次关上。
+ 开菜单时会自动打开游戏的 ESC 暂停菜单，游戏停住，鼠标能直接点菜单，不用再先按 ESC。关菜单时暂停菜单一起关掉，游戏接着走。不想要就在 Mod Settings 里关掉“开修改器时自动暂停”。
+ 热键和数值也能在游戏设置的 Mod Settings 里 TldHacks 那一页改，两边各项的名字是一样的。
+ 菜单默认按屏幕分辨率定大小。觉得不合适，在菜单里点加号、减号调。
+ 开着的开关左边有一道蓝条，关着的是灰字。
+ 一键清图、清任务物品、完成DLC任务这几个按钮要点两次。点第一下变红，字换成“再点一次确认”。
+ 菜单语言在 Mod Settings 里 TldHacks 那一页最上面的“Language / 语言”选，有 Auto、中文、English 三个。Auto 跟着游戏的语言走，游戏不是中文就显示英文。
+ 改完语言，按菜单热键重开菜单就换过来。Mod Settings 这一页要重启游戏才换。

### 存档和性能
+ 不掉帧。高频的改动按开关挂上和卸下，没开的功能完全不参与每一帧的计算。
+ 不坏存档。新加的设置都有默认值，读设置出错时用默认值顶上。出肉量这类只影响新生成的东西，旧存档里的不变。
+ 读档卡住会自动保护。载入存档卡住后关掉游戏，下次启动自动进安全模式，所有开关关掉，数值和热键保留。

### 一个键管几样的地方
+ U 在两个包里都管两样。动物雷达（MotionTrackerLite）什么时候按都开关，摆放物品时 U 又是转物体（PlacingAnywhere），所以摆放时按 U 雷达也会跟着开关。
+ 完整版的 F2 管两样。DeveloperConsole 用它打开控制台，完美摆放拿着物品时用它切换记住形状。拿着物品按 F2，两样会一起动。
+ 终极版的 F9 同时管两样，查看地堡分布（PrepperCache）、写诊断日志（TraderMoving）。
+ 终极版的左 Alt 摆放物品时是用鼠标转物体，制作界面里配合左键隐藏蓝图，平时按一下是 ItemPicker 捡身边的树枝石块。
+ 鼠标中键对着不同的东西干不同的事。对着建筑构件是复制（Architect），终极版里对着蜡烛是点灯，对着坐垫椅子是坐下，对着电视是开关。
+ B 和 H 在摆放物品时另有用处。B 平时打开建造菜单，摆放时是下移。H 在制作界面切换蓝图清单，摆放时是转物体。

## 九、剧情模式
剧情模式是独立的游戏程序，和沙盒不是同一个 exe，所以 mod 要单独装一遍。剧情包自带 mod 加载器（MelonLoader），一拖就能用，不用从沙盒目录拷任何东西。
装它不影响沙盒版，各有各的 Mods 文件夹，互不干扰。
剧情包可能有 bug，第 5 章这一版还没有进游戏实测过。
| 项目 | 第 1 到 4 章 | 第 5 章 |
| 网盘位置 | The Long dark 故事剧情模式_可能有bug没测试 文件夹里的 剧情模式第一章到第四章 | 同一个文件夹里的 剧情模式第五章 |
| 下载哪个 | 剧情材质包备份.001、.002 两个分卷 | 第五章剧情材质包备份.001、.002、.003 三个分卷 |
| 解出来是 | wintermute 文件夹 | episode5 文件夹 |
| 装到哪 | 游戏根目录\tld_dlc\wintermute\ | 游戏根目录\tld_dlc\episode5\ |
| 怎么进 | 游戏主菜单点剧情，进存档后按 Tab 打开菜单 | 游戏主菜单进第 5 章，读档后按 Tab 打开菜单 |
### 怎么装
+ 把分卷全部下载到同一个文件夹里，缺一个都打不开。
+ 右键 .001，用 7-Zip 打开，密码 tld2026。只点 .001 就行，它会自动把几个分卷合起来。
+ 两种装法选一种。省事的装法是把解出来的 wintermute（或 episode5）文件夹直接拖进 游戏根目录\tld_dlc\，选覆盖。稳妥的装法是进解出来的文件夹，把里面的 winhttp.dll、MelonLoader、Mods 三样拖进 游戏根目录\tld_dlc\wintermute\（或 episode5\），选覆盖。
+ 装完检查。tld_dlc\wintermute\（或 episode5\）里应该同时有原来的 tld.exe 和刚放进去的 winhttp.dll，两个在同一层。winhttp.dll 放进 MelonLoader 里面等于没装。
+ 按键在设置里的 Mod Settings 改。第一次启动慢一点，之后正常。
### 注意
+ 剧情目录里只放包里这三样，不要把沙盒的 mod 复制过去。剧情和沙盒的游戏版本不一样，复制过去会崩。
+ 包里那份 安装说明_必看.txt 有更细的排错步骤，装不上就看它。
+ 第 5 章读到剧情存档后，商人、美洲狮、传送、锁天气和调时间、极光点火、埋尸体、植物重生、搬猎物、任意丢弃会自动关掉并灰显，其余功能照常。第 5 章里也不能用清任务物品，免得卡住任务。

## 十、常见问题
! 装不上或者嫌麻烦
直接找群主远程安装，30 元一次，见第一章。
! 游戏能启动，但 mod 没加载
游戏能启动但 mod 管理器没起来，把游戏根目录的 version.dll 改名成 winhttp.dll 试试。还不行就找群主远程安装。
! 启动报 Runtime config not found
报 Runtime config not found 之类找不到 MelonLoader 文件的，多半是杀毒软件删了文件，或者解压时多套了一层文件夹。关掉杀毒软件（或者把游戏目录加白名单），重新解压覆盖一遍。还不行就找群主远程安装。
! 第一次启动很慢，黑框一直刷字
第一次启动会多等一会儿，黑框里刷字是正常的。
! 卡在加载画面
载入存档卡住后关掉游戏，下次启动会自动进安全模式，所有开关关掉，数值和热键保留。还是卡在加载，就删掉 Mods 文件夹里的 TldHacks.json，多半是配了非法的参数数值。
! 游戏设置界面打不开
包里这份 ModSettings.dll 是跟游戏版本配套的，请不要单独去更新它。如果装了别的 mod 把它覆盖成别的版本，游戏的设置界面可能打不开（日志里会看到 ModSettings 抛 MissingMethodException），从包里把 Mods\ModSettings.dll 还原回去就好。
! 解压报“无法打开为压缩文件”
要用 7-Zip（WinRAR 新版、Bandizip 也行），Windows 自带的解压不认这个格式。分卷的几个文件缺一不可，少一个也会报这个错。
! 只想更新 TldHacks
老用户只想换本体，解出来只拿 Mods\TldHacks.dll 覆盖就行，别的都不用动。10 月 28 日游戏更新后包里好几个别的 mod 也修了，从旧版升上来的建议整包重新装一遍。
! 菜单太大或太小
菜单默认按屏幕分辨率定大小，觉得不合适在菜单里点加号、减号调。
! 钓鱼的时候自动烤鱼
不想钓鱼的时候自动烤鱼，删掉 Mods 文件夹里的 CookWhileFishingReborn.dll。现在只有终极版带它。
! 体感变卡
体感变卡没办法，这个 b 游戏就是这么烂，要求高的开个 Lossless Scaling 就行。
! F5 快速保存
装了完整版的不要用 F5 快速保存，有可能坏档。存档的事拿不准，去群里问。
! 宝丽来
地图管理（现在在 TldHacks 的地图 & 界面页）里和宝丽来有关的功能不要用，比如“远景点不用宝丽来”，也可能坏档，默认关着。
! 中途加了别的 mod
如果在玩的过程中加了别的模组，推荐新开存档。
